# 作者的自創語言：沙語與灯語族

シャサフ式音樂理論裡的 Chy、Fu、Ahta、Chalaxata 這些名字，不是隨手取的代號，而是作者 LΛMPLIGHT 自創語言裡的詞。這份文件介紹那些語言，以及它們和音樂理論的關係。

- 內容依據原作者網站的公開文章整理（2026-11-11 閱讀），主要是〈シャサフ語に 50 の質問〉、沙語教科書的前幾課、〈Yffnoc（Shasavic Script）〉以及三種語言各自的〈はじめに〉。
- 這是**非官方的介紹**，我不會說這些語言，只能轉述作者自己的說明。要學請看[原作者的教科書](https://lamplight0.sakura.ne.jp/a/articles/)與[辭典](https://lamplight0.sakura.ne.jp/a/langs/sdic.php)。
- 樂理本身見[入門導讀](theory-guide.md)與[研讀筆記](../notes/shasavistic-theory.md)。

## 1. 不只一種語言

作者目前主要經營三種語言，合稱**灯語族（Lamplightic）**：

| 中文／日文漢字名 | 日文名 | 英文名 | 該語言中的自稱 | 作者的定位 |
|---|---|---|---|---|
| **沙語** | シャサフ語 | Shasavic | Safcyk | 像自然語言：例外多、歷史長，是作者思考的核心 |
| **莉語** | リサトプ語 | Lisatopian | Lisatopa | 像工程語言：發音與文法簡單、規則、例外少 |
| **玢語** | フェント語 | Faentian | Fēntā kehitsi | 仍在發展的藝術語言，以沙語的祖語為基礎的「自我二次創作」 |

三者有共同的來源。作者說自己從小就喜歡玩聲音，不知不覺做出許多語言，在小學到中學期間逐漸統合成一個叫**ユプケット**的語言；它的後代就是以沙語為中心的這三種語言。玢語則是沙語某個歷史階段的方言獨立出來的。

和音樂理論直接相關的是**沙語**，以下主要介紹它。

## 2. 沙語是什麼

「シャサフ」這個名字來自沙語的 **Schasaf**，意思是「世界觀」。

作者強調沙語**不是刻意設計出來的**：沒有「來決定要有哪些音」「來設計文法」這種步驟，而是從幼年的牙牙學語一路自然演變。作者後來做的事比較像自然語言裡會發生的事，例如替新事物命名、在幾個說法裡選一個當標準、改訂拼寫。

幾個基本事實（皆為作者自述）：

- **詞彙量**：超過 40,000 個詞。作者有整部以沙語講解的影片。
- **使用情況**：作者表示幾乎記得所有詞，可以不看資料自然地用它對話。
- **世界設定**：沒有設定在哪個國家或虛構世界使用；在影片裡常與近未來的氛圍連在一起。
- **歷史**：有實際的時代分期（準統合期 → 統合期 → 變革期 → 成熟期 → 安定期），古語不是設定，而是它真的一路變過來的樣子。
- **作者的名字**：LΛMPLIGHT 在沙語裡是 **Clefca**，意思是燈火。

## 3. 文字與發音

### 拉丁字母

平常用拉丁字母書寫，共 29 個字母：基本的 a 到 z，加上 **å、ä、ů**。

拼寫和發音的對應不規則，有一字多音，也有不發音的字母。幾個會讓人意外的拼法：

| 拼法 | 發音 | 類似的語言 |
|---|---|---|
| ch | /x/（像德語 Bach 的 ch） | 德語、波蘭語 |
| sch | /ʂ/（捲舌的 sh） | 德語 |
| sci | /ʂʲ/ | 義大利語 |
| z | /ts/ | 義大利語 |
| c | 在 a 前是 /k/，在 e 前變成塞擦音 | 義大利語一類的規則 |

這能幫你讀樂理的術語：**Chy** 的 ch 是 /x/，**Schu** 的 sch 是 /ʂ/，**Tschu** 的寫法也是同一套拼字習慣。

### 音韻的特色

- 母音只有 5 個，沒有長母音或雙母音。
- 子音有 21 到 24 個，而且**每個子音都分成兩種**：垂音（軟顎化，像俄語的硬子音）與斜音（顎化，像俄語的軟子音）。
- 母音的實際音色會受重音與前後子音影響而改變。
- 作者自己說，發音聽起來接近俄語或葡萄牙語。
- 重音位置不固定，但有傾向：沒有詞綴時，最後一個音節是閉音節就落在那裡，是開音節就落在倒數第二個音節。

### 固有文字：イフノーク（Yffnoc）

沙語另有自己的文字，叫 **Yffnoc**（イフノーク，沙字），2026 年 10 月公開說明。

- 它是**特徵文字**（featural script）：字形的部件對應發音的特徵，母音用點和線段組成。
- 最大的特色是**自由**，名字本身就和「自由」（yfnäska）有關。同一個字可以上下或左右翻轉而仍是同一個字，同一個詞可以有幾十種寫法。
- 書寫方向也自由：可以由左到右、由右到左，也可以直寫。句號、逗號等標點放在第一個詞周圍，同時標示書寫方向。
- 作者說明這些規則只是指引，只要看得懂，可以為了美觀改變字形。

字形表是圖片，請看原站的說明文章。

## 4. 文法的樣子

沙語是**例外很多的屈折語**，同時大量使用詞綴。作者自己說它「難但深」。

### 詞形變化很重

名詞會隨著數、格、限定性等變化，再加上詞綴，一個詞可以有非常多的形式。許多基本詞的複數必須硬背：

| 意思 | 單數 | 複數 |
|---|---|---|
| 手 | nusch | ney |
| 杯子 | yup | yspäy |
| 人 | noscha | fmyluim |

### 六個格

| 格 | 大致的意思 |
|---|---|
| 平格 | 不及物動詞的主語；無生物的受詞 |
| 方格 | 有生物的受詞 |
| 吹格 | 無生物當及物動詞的主語 |
| 生格 | 從…、比…、關於… |
| 與格 | 給…、往…、為了… |
| 副詞格 | 在（地點）、用（手段）、在（時間）、被… |

以上是平常使用的體系；作者說另有一套五個格的體系，視情況選用。

其中「吹格」反映了沙語的一個特點：只有在主語是無生物時，才特別標記及物動詞的主語（能格性）。例如「風吹」與「風搖動葉子」裡的「風」，在沙語是不同的格。

### 其他特點

- **成對的東西有專用的數**：腳、手這類成對的事物，除了單數與複數，還有「一雙」和「好幾雙」的形式。
- **「我的」會隨關係而變**：我的筆、我的老師、我的孩子、我的朋友，用的是不同的形式。
- **主語可以省略**，像日語和韓語。
- **定冠詞是接在詞尾的**，像瑞典語。
- **「我們」區分是否包含聽話者。**
- **語序相對自由**，但傾向不把動詞放在句尾，主題放前面、重點放在動詞前。
- **敬語**：有口語詞與書面詞成對的現象，請求的說法也有從命令到非常客氣的許多層級。

### 語面理論

作者不用「名詞、動詞、形容詞」這套詞類來描述自己的語言，而用自創的**語面理論**。大致的對應是：

| 一般的詞類 | 語面理論的說法 |
|---|---|
| 名詞 | 格体 |
| 動詞 | 実心（在句中當中心時稱為心子） |
| 形容詞 | 飾定 |
| 修飾名詞的成分 | 連格 |
| 修飾動詞、形容詞的成分（副詞） | 連象 |
| 修飾整個句子的成分（連接詞等） | 連包 |

這和音樂理論的作風很像：不沿用既有的框架，而是從頭定義一套自己覺得更合理的術語。

## 6. 語言和音樂理論的關係

作者把理論區分成兩層：與沙語直接相關的部分是沙語文化圈的音樂（**沙音樂**，主要用 41 平均律）；不直接涉及語言的理論部分，暱稱為「オトノマ」。但理論的術語大量取自沙語，而且照沙語的規則運作。

### 術語本身就是沙語

| 術語 | 在理論裡的意思 | 語言上的性質 |
|---|---|---|
| Ah、Ya、Cha、La、Ma、Za、Gha | 0 到 6 次元的名字 | 次元名。原作者說這些基本上是沙語裡的名稱 |
| Chy／Fu、Ly／Su、My／Pu、Zy／Tschu | 各次元上昇／下降一步 | 倍分名，同樣是沙語的詞 |
| Chyli、Fuli、Chys… | 音的唱名（ハーモニム） | 把倍分名依規則接合，接合時會發生縮短與音變 |
| AhChyLy… | 和弦名（コードニム） | 把構成音的唱名列出來 |
| Ahta、Chyta、Futa | 主、屬、下屬的機能名 | 位置的名字加上 -ta |
| -cra、-vra、-na、-crana、-navra | 各種拡動 | 接在機能名後面的詞尾 |
| Chalaxata、Nafchalica | 官方的演奏工具、和音圖 | 以沙語命名 |

作者在講解唱名的影片裡提到，這些名字的發音經過調整，以符合沙語的音韻。接合規則裡的細節（例如 Chy + Ly → Chyli、Tschu 在某些位置變成 k）就是沙語式的音變。

### 讀機能式時用的是沙語的詞

把機能式唸出來時，用的是沙語的功能詞與數詞：

| 沙語 | 意思 | 例 |
|---|---|---|
| pa | 「在…上」，表示最低音 | AhChyLy/Ly 的斜線唸作 pa |
| glui | 省略 | Ahta glui Cha |
| u／av | 加、和 | Ahta u mas… |
| mas、byl、tram | 1、2、3 | 指第幾個槽 |
| nyli | 0 | |

其中 mas、byl 就是上一節數詞表裡的 1 和 2；av 在沙語裡是「然後、和」。

### 合成機能用到詞形變化

兩個機能疊在一起時，英文用 with、under、plus 三種說法區分；沙語則靠**詞形變化**，例如 Futai Chyta、Futa fa Chytu、Chytiei Futa。這是屈折語的做法：關係寫在詞尾，而不是靠額外的介系詞。

## 7. 莉語與玢語簡介

**莉語（Lisatopian）**是三者中最容易的。作者介紹它發音與文法都簡單、例外少：

- 動詞一律以 -e 結尾，名詞一律以 -a 結尾，改詞尾就能轉換詞類：peke（學）→ peka（學習），late（在）→ lata（地方）。
- 詞可以直接組合：peke（學）+ lata（地方）= pekellata（學校）。
- 另有更嚴格的「論理莉語」，以及莉語自己的文字（莉字），原站提供輸入工具。

**玢語（Faentian）**是以沙語的祖語為基礎再創作的語言，作者稱它仍在發展中，詞彙與文法可能微調。它的語序與日語相近：動詞一定放句尾，主題加上標記 tā 放前面。作者於 2026 年 7 月公開了學習資料。
